Inner Development Loop:
1. Make a change
2. Compile the application
3. Run tests
4. Run the application

For faster linking (overall compilation) run
- cargo install -f cargo-binutils
- rustup component add llvm-tools-preview

For improved productivity (active runs of cargo check)
- cargo install cargo-watch
- cargo watch -x check (compile after every change)
- cargo watch -x check -x test-x run (check, test, run)

CI
- cargo test (running tests)
- cargo tarpaulin --ignore-tests (shows coverege) (cargo install cargo-tarpaulin)
- cargo clippy -- -D warnings (for linting) (rustup component add clippy)
#[allow(clippy::lint_name)]
- cargo fmt -- --check (for auto formatting) (rustup component add rustfmt)
- cargo audit (for security vulnerability checks) (cargo install cargo-audit)

Macro expansion
- cargo install cargo-expand (for expanding macros)

Database
cargo install sqlx-cli --no-default-features --features postgres

Migration
sqlx migrate run
